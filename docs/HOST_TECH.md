<h1>Host (technical)</h1>

**N/A.** The host is an actor, not a component: nothing about the host is implemented in
SDEP. See [Host](./HOST_FUNC.md) for the process.

However, what the host produces does reach SDEP, as fields on a listing submitted by a platform:

- The **registration number**, from the registration system
- The **self-declaration** (`declaredAsShortTermRental`), given on the platform

Both are in [Listing (technical)](./LISTING_TECH.md#data). The registration system itself
is outside SDEP too.
