<h1>Host</h1>

The following process is relevant in the context of SDEP but falls outside the scope of the SDEP implementation itself:

- **A host registers**, where applicable, a **listing address** in a **registration system** and receives a **registration number**.
- **A host registers a listing** with an **address** on a **platform** and, where applicable, provides the associated **registration number**.
- **A host provides a self-declaration** on the platform, indicating whether the listing is a short-term rental located in a regulated area.
